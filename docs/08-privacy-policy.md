# 云手机 · 隐私政策（AGC 模板填写稿）

> 用途：粘贴到 AGC「应用信息 → 隐私政策」的华为模板中。
> 原则：应用本身**不收集任何个人信息**，数据全程在用户自建局域网内；对应模板各节均按"不涉及/无"如实填写。

## 产品简介
```
云手机是一款局域网远程控制应用。您可以通过它在手机上连接并实时控制局域网内的被控端设备（如安卓设备、智能盒子等），支持实时画面查看、触控操作与画质调节。所有连接均直连您指定的被控端设备，数据不经过任何第三方服务器。
```

## 增加版本变更说明
```
v1.0.0 首次发布：支持局域网被控端扫描发现、设备直连、实时远程控制与画质设置。
```

## 增加摘要（隐私声明摘要）
```
云手机为局域网远程控制工具。应用本身不收集任何个人信息：您的账号信息、设备信息与画面数据均仅存储于您自建的被控端设备上，并通过局域网直接传输，不经过我们或任何第三方服务器。应用仅申请「联网」与「获取网络信息」两项基础权限，用于连接被控端及在局域网内扫描发现设备。
```

## 1.2 个性化推荐说明
```
不涉及。本应用不包含任何个性化推荐功能。
```

## 1.3 广告和营销说明
```
不涉及。本应用不包含任何广告或营销功能。
```

## 2. 设备权限调用
```
本应用仅申请以下基础权限：
1. 网络访问权限（INTERNET）：用于连接您指定的被控端设备，传输信令与画面数据；
2. 获取网络信息权限（GET_NETWORK_INFO）：用于读取当前网络状态，以便在局域网内扫描并发现被控端设备。
本应用不申请位置、相机、麦克风、通讯录等任何敏感权限。对被控端设备的触控、按键操作通过应用内指令注入实现，无需设备端权限。
```

## 3. 对未成年人的保护
```
本应用面向一般用户，不针对未成年人设计。若您为未成年人，请在监护人指导下使用本应用及您的被控端设备。我们不会主动收集未成年人个人信息。
```

## 4. 与第三方共享
```
不涉及。我们不会与任何第三方共享您的个人信息。您的数据仅存在于您自建的被控端设备中；仅在法律法规要求或政府机关依法要求时，我们才可能依法提供相关信息。
```

## 5. 第三方 SDK
```
不涉及。本应用未集成统计、广告、推送、地图等任何第三方软件开发工具包（SDK）。
```

## 6. 管理您的个人信息

```

## 7. 信息存储地点及期限
```
7.1 存储地点：您的数据存储于您自行部署的被控端设备上（通常位于您的个人局域网内），不会上传至我们或任何第三方服务器。
7.2 存储期限：本应用仅在手机本地保存登录凭证（服务器地址、用户名、访问令牌）与画质设置。您可随时在应用内「退出登录」清除凭证，或卸载应用删除全部本地数据。被控端设备上的数据存储期限由该设备的管理者决定。
```
> 跨境处理声明：不涉及，无需增加。

```

## 填写操作清单（AGC 页面）
1. 产品简介 ← 粘贴「产品简介」；
2. 删除模板里「用于 … 的应用」占位；
3. 个性化推荐 / 广告营销 → 分别粘贴"不涉及"文案（不要留空）；
4. 设备权限调用 → 粘贴权限说明；
5. 未成年人保护 → 粘贴；
6. 三方共享 / 第三方SDK → 粘贴"不涉及/无"；
7. 存储地点及期限 → 7.1/7.2 分别粘贴；
8. 自定义章节 → 粘贴「局域网直连说明」；
9. 联系方式 → 填真实邮箱（必换）。
